One funny line: a genie is asked for unlimited wishes, and answers with the most limited modern thing there is — a subscription. The program in `main.ts` writes that single line (76 characters) to `entry.txt` in the output directory, after checking it against the 200-character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
